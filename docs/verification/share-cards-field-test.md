# 공유 카드 V1.10.0 검증 기록

설계 스펙(`docs/superpowers/specs/2026-11-01-share-cards-design.md`) §9(검증)에 따른 기록 문서입니다. 공유 창의 비율 고르기(게시물 4:5 / 스토리 9:16)와 "보낼 것" 띠, 위성 카드·사진 카드·투명 스티커, 인스타그램·페이스북 여러 장 보내기, "지나간 길" 해시태그(내장 오프라인 데이터)를 다룹니다. DB는 바꾸지 않았습니다(9판 그대로).

> **경고**: `connectedDebugAndroidTest`는 끝나면 앱을 지워 그 휴대폰의 기록이 사라집니다.
> connected 테스트는 S22 `R5CT43TFS9A`에서만, S25 `R3CY903ZYQV`에는 아무것도 하지 않습니다(설치는 사용자가 요청할 때 DB·DataStore 백업과 표 개수 비교 뒤에). **실제 SNS에는 올리지 않습니다.** 작성 화면에 사진이 들어온 것만 보고 게시를 누르지 않은 채 뒤로 나옵니다.
