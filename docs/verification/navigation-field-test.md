### 준비

1. 카카오 REST API 키를 프로젝트 루트 `secrets.json`에 넣습니다: `{ "kakaoRestApiKey": "..." }` (Git에 올라가지 않음).
2. 카카오 개발자 콘솔의 **제품 설정 > 카카오맵 > 사용 설정**이 ON인지 확인합니다. 꺼져 있으면 검색이 403으로 실패합니다.
3. 휴대폰에 USB 디버깅으로 연결하고 설치합니다.

   ```bash
   adb devices
   ANDROID_SERIAL=<시리얼> ./gradlew :app:installDebug
   ```

4. 앱을 처음 실행해 권한(정밀 위치, 백그라운드 위치, 알림, 배터리 최적화 제외)을 허용하고 **경로 데이터**(필수 2개, 약 80MB)를 와이파이로 내려받습니다. 설정 화면의 「경로 데이터」에서 설치 여부를 확인합니다.
5. 항목 6(비행기 모드) 전에 안내 시작 후 「내려받은 지도」 용량이 0이 아닌지 설정 화면에서 확인합니다.

### 측정 방법

- **배터리 (항목 7)**: 안내 시작 직전의 배터리 %와 종료 직후의 %를 메모하고, 안내 시간(분)으로 시간당 소모를 계산합니다. 화면은 끈 상태로 둡니다.
- **ETA (항목 4)**: 1km 안내 음성이 나올 때 안내된 도착 예정 시각을 적고, 실제 도착 시각과의 차이(분)를 기록합니다. 합격 기준은 ±10분입니다.
- **남은 거리 (항목 4)**: 1km 안내가 나오는 순간 화면의 남은 거리와 안내 음성의 남은 거리를 비교합니다.
- **재탐색 (항목 5)**: 경로에서 벗어난 순간부터 "다시 탐색" 재탐색 안내가 들릴 때까지 초를 잽니다.
