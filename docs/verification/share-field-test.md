# 활동 공유하기 V1.5.0 검증 기록

설계 스펙(`docs/superpowers/specs/2026-10-31-share-activity-design.md`) §7(검증)에 따른 기록 문서입니다. 요약 카드·여행 기록 화면·구간 요약의 [공유] 단추, "활동 공유하기" 시트(자동 글, 감정 칩, 앱별 보내기, 파일이 없을 때 세로 요약 이미지 만들기), 설정의 기본 해시태그를 다룹니다. DB는 v6에서 v7로 올랐습니다(`trip_label`에 `shareText`, `shareStamp`).

> **경고**: `connectedDebugAndroidTest`는 끝나면 앱을 지워 그 휴대폰의 기록이 사라집니다.
> connected 테스트는 S22 `R5CT43TFS9A`에서만, S25 `R3CY903ZYQV`에는 아무것도 하지 않습니다(설치는 사용자가 요청할 때 DB 백업과 개수 비교 뒤에). 실제 SNS에는 올리지 않고, 기기 시험은 가짜 시작기·가짜 클립보드로 인텐트 내용만 확인합니다.

스펙 §7.1의 PC 확인 범위:
- 자동 글: 날짜(하루, 여러 날의 같은 달·달 바뀜·해 바뀜), 제목(직접 바꾼 제목, 지역 없음), 숫자(상승 고도 1 m 미만, 이동 시간 0), 해시태그가 하나도 없을 때
- 해시태그: 정리 규칙(특수문자 제거), 겹침 제거, 장소 나누기, 설정 입력 정리(`자출 한강`, 빈 값, 100자)
- 감정 칩: 켜고 끄기, 직접 지운 해시태그, `#상쾌함` 오인 없음, 해시태그 줄이 없는 글
- 보낼 파일 고르기: 오래된 파일 제외, 지운 파일 제외, 스토리는 세로 우선, 이메일 20 MB, 크기를 모름, 아무것도 없음 → 만들기
- 저장 규칙: 자동 글과 같으면 null, 다르면 저장, 기록 표시가 바뀌면 알림 줄
- 시트 상태 기계(`ShareViewModel`): 만들고 나서 보내기, 만들기 취소·시트 닫기·다른 단추 뒤에는 보내지 않음, 만들 수 없음 사유와 [다시 시도], 앱이 멈춰 있는 동안(STOPPED) 온 보내기 이벤트는 앱이 돌아오면 한 번만 처리, 시트가 만드는 중일 때는 미리보기 화면 게이트가 열리지 않음
- 인텐트와 앱 찾기는 기기 시험(아래)에서 확인

## 이 버전에서 정한 판정

스펙이 말하지 않았거나 스펙의 말을 바꾼 것 가운데 화면이나 동작이 달라지는 것입니다. 실사용 때 이 기준으로 봅니다.

- **여행 화면의 공유 아이콘 자리**: 스펙 §1.1의 "위쪽 막대 오른쪽" 대신 제목 줄의 ✎ 앞에 둡니다(계획 승인대로).
- **안내(길찾기) 요약의 [공유] 순서**: 기록 요약과 안내 요약 모두 영상 단추 바로 아래에 옵니다. 안내 요약은 "여행을 완료했습니다" → [영상 만들기] → [공유] → [여러 날로 바꾸기] 순서입니다.
- **알림 방식**: "글을 복사했습니다. 붙여 넣으세요" 등은 짧은 `Toast`입니다. 시트가 따로 창이라 화면 아래 알림은 시트에 가려지기 때문입니다.
- **오류 문구**: 인터넷 없음·영상 만드는 중의 문구는 스펙 §2.5의 문구를 씁니다(`StartResult.message`가 아님).
- **진행 중 여행**: 끝나지 않은 여행도 공유 단추는 보이고(10 m 이상 끝난 구간이 있으면), 이미지가 필요한 단추만 "여행을 마치면 그림을 만들 수 있습니다"로 흐려집니다. 그동안은 "보낼 것" 줄 대신 이 문구가 보입니다.
- **영상에만 크기 표시**: "보낼 것" 줄의 MB 크기는 영상에만 붙습니다. 이미지에는 크기를 쓰지 않습니다.
- **[저장]으로 만든 이미지**: 이미지를 새로 만들고 [저장]하면 "갤러리에 저장했습니다"와 함께 "영상을 만들었습니다" 알림이 남을 수 있습니다(누르면 만든 이미지가 열림).
- **만드는 중 글 고치기**: 이미지를 만드는 동안에도 글 상자를 고칠 수 있고, 보내는 글은 단추를 누른 때의 글입니다.

## 판정

- PC 테스트와 기기 테스트(최종 수정 후 전체)가 통과하고 위 15개 항목이 모두 합격이면 `CHANGELOG.md`의 V1.5.0을 확정하고(「개발 중」 표기 제거) 태그를 붙입니다.
- 불합격 항목은 원인 수정과 회귀 테스트 추가 뒤 그 항목만 다시 확인하고, 여기에 재검증 결과를 덧붙입니다.
- S25는 사용자가 요청할 때 DB 백업과 기록 개수 비교 뒤에 설치합니다.
