# V1.2.1 보완 — 누적 지도 목록·지도 역할 나누기, 여행 기록 [다시 가져오기] 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 누적 지도 목록을 "누르면 기록으로 가는 카드"로, 지도 선 누르기를 "강조 + 정보 카드"로 나누고, 여행 기록 화면에 [다시 가져오기]를 더한다.

**Architecture:** `CumulativeMapViewModel`의 선택 상태는 지도에서만 바뀌고(목록 줄은 바로 이동), 화면에 정보 카드를 더한다. 여행 기록은 `TripDetailViewModel.refetchHeartRate()`가 구간마다 기존 `PostProcessor.refetchHeartRate(segmentId)`를 차례로 부른다.

**Tech Stack:** 기존과 동일. 버전 1.2.1 그대로.

**Spec:** `docs/superpowers/specs/2026-10-18-trips-postprocess-design.md` §6.8, §6.9 (§6 전체와 V1.2.1 계획 `2026-10-27-v1.2.1-fixes-and-cumulative-map.md`의 Global Constraints가 그대로 적용).
