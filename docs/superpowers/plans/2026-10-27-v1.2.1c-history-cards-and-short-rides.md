# V1.2.1 보완 2 — 기록 목록 카드와 짧은 기록 처리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 짧은 기록(10 m 미만)을 끝낼 때 버릴 수 있게 하고 기존 것은 숨긴 뒤 [정리]로 지우게 하며, 기록 목록을 경로 미리보기가 있는 카드와 달 머리글로 바꾼다.

**Architecture:** 짧은 판정은 core `MIN_RIDE_DISTANCE_M` 재사용. 요약의 버리기 대화상자는 공용 `SummaryExtras`(기록·안내 요약)에, 삭제는 기존 `RideStore.deleteSegment/deleteTrip`. 목록은 `HistoryViewModel`이 여행마다 카드 모델(`TripCard`)을 만들고(단순화 경로·사진 수·심박 집계), `HistoryScreen`이 달별로 묶어 그린다. 미리보기는 Compose `Canvas`(지도 타일 없음).

**Tech Stack:** 기존과 동일. 버전 1.2.1 그대로. DB 4 그대로(필요하면 DAO 쿼리만 추가).

**Spec:** `docs/superpowers/specs/2026-10-18-trips-postprocess-design.md` §6.10, §6.11.
