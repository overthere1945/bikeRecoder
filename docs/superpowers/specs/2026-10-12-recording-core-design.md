# 기록 코어 설계 (하위 프로젝트 2 — V1.1.0)

- 작성일: 2026-10-12
- 대상 버전: V1.1.0
- 선행: 내비게이션 V1.0.0 (`docs/superpowers/specs/2026-10-05-navigation-design.md`, 브랜치 `feature/navigation-v1.0.0`)
- 상태: 섹션 1~4 사용자 승인 완료 (2026-10-12). 작성 후 사용자 위임에 따라 계획·구현 진행

## 0. 맥락

bikeRecoder 4단계 로드맵 중 2단계다. 1단계(내비게이션)가 만든 여행(Trip), 위치 수신(`LocationSource`), 포그라운드 서비스, 음성 출력(`VoiceOutput`), 지도(`BikeMap`)를 재사용해 **GPS 주행 기록**을 더한다. 3단계(여러 날 기록 합치기·사진·심박)와 4단계(영상)는 이 단계가 저장하는 **주행 구간·위치 기록**을 그대로 쓴다.

사용자 요구(원문 요지):
- 기록 시작·정지 UI, 시작 시 음성 안내.
- 1km마다 평균 속도·이동 거리·이동 시간 음성 안내.
- 정지하면 자동 일시정지 + 음성, 다시 움직이면 재개 + 음성.
- 자동/수동 일시정지를 UI에서 선택.
- 현재 속도·고도·평균 속도·최고 속도 표시.

확정된 결정:
- 안내를 시작하면 기록도 자동 시작(설정으로 끌 수 있음). 기록만 단독 시작도 가능.
- 기록 화면은 **지도 페이지 ↔ 숫자 페이지**를 옆으로 넘겨 전환.
- 구조는 **하나의 "주행 서비스"**: GPS를 한 번 받아 기록 엔진과 안내 엔진에 나눠 준다.

## 1. 범위

### 1.1 포함
- 기록 엔진(core): 거리·이동 시간·경과 시간·현재/평균/최고 속도·고도·누적 상승/하강, 자동/수동 일시정지.
- 기압계 + GPS 고도 융합, 해발 고도 변환.
- 주행 서비스로 확장(안내 + 기록, 알림 1개).
- 음성: 기록 시작, 일시정지, 재개, 1km 안내(기록 단독 / 안내와 합친 한 문장).
- Room DB v1 → v2: 주행 구간, 위치 기록 테이블. 기존 데이터 보존.
- 화면: 지도 메인 [기록 시작]·주행 중 배너·메뉴의 [기록], 기록 화면(2페이지), 안내 화면의 기록 수치, 구간 요약, 기록 목록, 여행 상세, 구간 상세(지도·수치·고도/속도 그래프), 삭제.
- 설정: 안내 시작 시 기록 자동 시작, 기본 일시정지 방식(자동/수동).
- 앱 강제 종료 시 복구.

### 1.2 제외
- GPX 내보내기, Strava·삼성 헬스 연동, 칼로리.
- 심박·사진(3단계), 영상(4단계).

## 2. 구조

```
GPS(1초) ─┐
기압계 ───┼─► 주행 서비스 (포그라운드 서비스 1개, 알림 1개)
          │       ├─► 기록 엔진(RecordingSession) ──► 주행 구간·위치 기록 저장 (Room)
          │       └─► 안내 엔진(NavigationSession, 안내 중일 때만)
          └─ 음성: 기록 중이면 1km 안내는 기록 쪽이 안내 정보를 합쳐 한 문장으로 낸다
```

### 2.1 core (순수 Kotlin, JVM 테스트)

| 단위 | 책임 |
|---|---|
| `RideStats` | 이동 거리, 이동 시간, 경과 시간, 현재/평균/최고 속도, 현재 고도, 누적 상승/하강 |
| `AutoPauseDetector` | 자동 일시정지·재개 판정(3.2) |
| `AltitudeFusion` | 기압 고도 + GPS 보정, 기압계 없으면 GPS 평활(3.4) |
| `RecordingSession` | 위 셋을 묶는 기록 엔진. 상태 RECORDING / PAUSED(AUTO\|MANUAL) / STOPPED. 이벤트 Started, Paused(auto), Resumed, KmReached |
| `KoreanPhrases` 확장 | 기록 문구, 1km 합친 문장(3.5) |

### 2.2 app

| 단위 | 책임 |
|---|---|
| 주행 서비스 (기존 안내 서비스 확장) | 포그라운드 위치 서비스. 기록 또는 안내가 하나라도 진행 중이면 유지 |
| `RideController` | 기록 시작·정지·일시정지·재개, 안내 시작 시 기록 자동 시작, 위치 한 스트림을 기록·안내에 분배, 음성 조율, 저장 |
| `BarometerSource` | `Sensor.TYPE_PRESSURE` 수신. 없으면 비활성 |
| Room v2 | `ride_segment`, `track_point` 테이블 + v1→v2 마이그레이션 |
| 화면 | 2장 |
| 설정 | `autoStartRecordingWithNavigation`(기본 켜짐), `autoPauseEnabled`(기본 켜짐) |

### 2.3 여행과의 관계
- 기록 시작 시 진행 중인 여행이 없으면 일정 유형(당일/여러 날)을 한 번 묻는다. 진행 중인 여러 날 여행이 있으면 이어서 기록할지 묻는다(1단계 TripStart 흐름 재사용).
- 한 여행 안에 **주행 구간이 여러 개** 쌓인다(기록 시작~정지가 한 구간).

## 3. 화면 흐름

```
[지도 메인] ─[기록 시작]─► (일정 유형 확인) ─► [기록 화면] ─[정지]─► (여행 종료 선택) ─► [구간 요약]
     ├─[목적지→경로 계획→안내 시작]─► [안내 화면 + 기록] ─(도착)──────────────────────┤
     └─[☰ 기록]─► [기록 목록] ─► [여행 상세] ─► [구간 상세]
```

### 3.1 지도 메인
- 오른쪽 아래 **[● 기록 시작]**.
- 기록 또는 안내 진행 중이면 위쪽 배너 "● 주행 중 · {거리} · {이동 시간} [보기]" (1단계 "안내 중 [보기]" 배너를 확장).
- 오른쪽 위 메뉴: [기록], [설정].

### 3.2 기록 화면 (HorizontalPager 2페이지)
- 지도 페이지: 지나온 경로 + 현재 위치, 하단 요약(현재 속도·거리·이동 시간·평균).
- 숫자 페이지: 현재 속도(크게), 거리, 이동 시간, 평균, 최고, 고도, 누적 ↑/↓.
- 상단 칩 **[자동 일시정지 ON/OFF]** 즉시 전환(세션 중 변경, 기본값은 설정).
- 하단 [일시정지]/[재개], [정지]. 자동 모드에서도 수동 일시정지 가능.
- 일시정지 중: 상단 띠 "일시정지됨 (자동|수동)", 숫자 흐리게.
- [정지] → "기록을 끝낼까요?" 확인.

### 3.3 안내와 함께
- 안내 시작 시 기록 자동 시작(설정).
- 안내 화면 회전 카드 아래 기록 한 줄 "{거리} · {이동 시간} · 평균 {x}", 옆으로 넘기면 숫자 페이지.
- 목적지 도착 → 안내·기록 함께 종료.
- 도중 [종료]: 당일 [안내만 끝내기 (기록 계속)] / [모두 끝내기]; 여러 날 [안내만 끝내기] / [오늘은 여기까지] / [여행 완료]. (기록이 꺼져 있으면 1단계 선택지 그대로)

### 3.4 기록 종료 후
- 여행 종료 선택(당일 → 완료, 여러 날 → [오늘은 여기까지]/[여행 완료]), 이어서 **구간 요약**(거리·이동 시간·평균/최고·누적 상승·지도) → [확인] → 지도 메인.

### 3.5 기록 목록·상세·삭제
- 목록: 여행 카드 "{날짜} · {당일|여러 날(N일)} · {총 거리} · {총 이동 시간}", 최신순.
- 여행 상세: 날짜별 구간 목록 + 여행 합계.
- 구간 상세: 지도(경로·출발/도착 마커), 수치(거리, 이동 시간, 경과 시간, 평균·최고, 누적 상승·하강, 최고·최저 고도), **고도 그래프·속도 그래프**(가로축 거리, Compose Canvas).
- 여행·구간 길게 눌러 삭제(확인). 진행 중인 구간·여행은 삭제 불가.

## 4. 핵심 로직

### 4.1 위치 거르기
- 정확도 > 30m 제외. 직전 채택 위치 대비 구간 속도 > 80km/h 제외.

### 4.2 자동 일시정지
| 전이 | 기준 | 음성 |
|---|---|---|
| 기록 → 일시정지 | 속도 < 3km/h가 5초 연속 | "일시정지되었습니다" |
| 일시정지 → 기록 | 속도 ≥ 5km/h가 2초 연속, 또는 정지 지점에서 15m 이상 이동 | "기록을 다시 시작합니다" |
- 수동 모드: 버튼으로만 전이, 음성 동일.
- 일시정지 동안의 거리·시간은 기록하지 않는다(재개 시 정지 지점→재개 위치 거리도 더하지 않음).

### 4.3 거리·시간·속도
- 거리: 기록 중 상태에서 채택 위치 간 거리 합.
- 이동 시간: 기록 중 상태 시간의 합. 경과 시간: 시작~정지(일시정지 포함).
- 현재 속도: `fix.speedMps` 우선, 없으면 구간 속도. 약 3초 이동 평균. 일시정지 중 0.
- 평균 = 거리 ÷ 이동 시간(이동 시간 0이면 0).
- 최고 = 3초 창 중간값들의 최댓값.

### 4.4 고도
- 기압계: `SensorManager.getAltitude(1013.25, p)` 상대 고도, 5초 평균. 수직 정확도 ≤ 10m GPS 고도와의 차이 중간값으로 오프셋 보정(처음 60초, 이후 5분마다 EMA 0.1).
- 기압계 없음: GPS 고도 중간값 필터(5) + 평활.
- 해발 변환: API 34+ `AltitudeConverter`로 MSL 고도 사용(실패 시 원래 고도).
- 누적 상승/하강: 기준점 대비 ≥ 3m(기압) / ≥ 5m(GPS) 변할 때만 누적하고 기준점 갱신.

### 4.5 음성
| 상황 | 문구 |
|---|---|
| 기록 시작 | "기록을 시작합니다" |
| 일시정지 | "일시정지되었습니다" |
| 재개 | "기록을 다시 시작합니다" |
| 1km (기록만) | "{n}킬로미터 이동. 평균 속도 {x.x}킬로미터, 이동 시간 {시간}입니다." |
| 1km (안내와 함께) | "{n}킬로미터 이동. 평균 속도 {x.x}킬로미터, 이동 시간 {시간}. 남은 거리 {거리}, 도착 예정 {시각}입니다." |
- {시간}: 1시간 미만 "{m}분", 이상 "{h}시간 {m}분".
- 기록 중이면 안내 엔진의 1km 안내는 끄고 기록 쪽이 낸다(중복 금지). 기록이 꺼진 안내는 1단계와 동일.
- km 기준 = **해당 여행의 그날(Asia/Seoul) 기록 거리 합**(같은 날 여러 구간 이어 셈, 날짜 바뀌면 1부터).
- 회전 안내 임박 시 1km 안내를 미루는 규칙은 1단계와 동일.

### 4.6 저장·복구
- 위치 기록은 5초마다 일괄 저장, 같은 트랜잭션에서 구간 합계 갱신.
- 구간 `endedAt == null`로 남은 채 앱이 재시작되면 "기록이 중단되었습니다" [이어서 기록](같은 여행 새 구간) / [종료](마지막 저장 시각으로 닫기).
- 서비스 비정상 재시작 알림 "주행이 중단되었습니다. 눌러서 재개"(1단계 알림 확장).

### 4.7 오류 처리
| 상황 | 처리 |
|---|---|
| 기압계 없음 | GPS 고도 방식, 알림 없음 |
| GPS 10초 이상 없음 | "GPS 신호 약함" 표시, 거리 증가 없음 |
| 저장 실패 | 로그 + "기록 저장에 문제가 있습니다" 1회 표시, 다음 주기 재시도 |
| 위치 권한 없음 | [기록 시작] 시 권한 안내로 연결 |

### 4.8 데이터
- `ride_segment(id, tripId FK CASCADE, startedAt, endedAt?, localDate, distanceM, movingTimeMs, elapsedMs, maxSpeedMps, ascentM, descentM, minAltitudeM?, maxAltitudeM?)`
- `track_point(id, segmentId FK CASCADE, timeMillis, lat, lon, altitudeM?, speedMps?, accuracyM)` — 기록 중 상태의 채택 위치만.
- DB 버전 2, 1→2 마이그레이션은 테이블 추가만.

## 5. 검증

### 5.1 PC 자동 테스트 (core)
자동 일시정지(3km/h 5초 정지, 4초는 아님, 5km/h 2초 재개, 4km/h 굴림 비재개, 15m 이동 재개, 수동 모드), 거리·시간(일시정지 제외, 정확도·튐 제외, 이동/경과 분리), 속도(평균, 튐 1회가 최고에 미반영, 일시정지 중 0), 고도(기압 오르내림, 보정, ±2m 출렁임 비누적, 50m 오르막 50±3m, 기압계 없음 전환), 음성 문구(기록만/합친 문장, 시간 읽기, 시작·일시정지·재개), 1km 이어 세기(같은 날 이어, 다음 날 1부터).

### 5.2 휴대폰 자동 테스트 (GPX 재생)
| 시나리오 | 기대 |
|---|---|
| ① 기록만 3km | 시작 1회, 1km 3회, 저장 거리 3km ±1% |
| ② 신호 대기 2회 | 일시정지·재개 각 2회, 이동 시간 < 경과 시간 |
| ③ 안내+기록 | 1km 안내 한 문장 1회, 남은 거리·도착 예정 포함 |
| ④ 기록 중 강제 종료 후 재실행 | 중단 확인 → [이어서 기록] 시 같은 여행 새 구간 |
| ⑤ 도착 | 안내·기록 함께 종료, 구간 요약 |
| ⑥ DB 마이그레이션 | v1 데이터 → v2 후 기존 여행 유지 |
화면 테스트: 페이지 넘기기, 자동 일시정지 칩, 정지 확인, 목록→상세, 길게 눌러 삭제.

### 5.3 실주행 체크리스트
| # | 항목 | 합격 기준 |
|---|---|---|
| 1 | 기록만 30분 | 거리 삼성 헬스(Watch7) 대비 ±3% |
| 2 | 신호 많은 도심 | 신호마다 일시정지·재개 안내, 이동 시간 실제와 일치 |
| 3 | 수동 모드 | 자동 일시정지 없음, 버튼으로만 |
| 4 | 오르막 코스 | 누적 상승 삼성 헬스 대비 ±15% |
| 5 | 최고 속도 | 실제와 비슷, 70km/h 이상 터무니없는 값 없음 |
| 6 | 화면 꺼짐 1시간 | 1km 안내 모두 들림, 배터리 시간당 12% 이하(안내+기록) |
| 7 | 안내와 함께 | 1km 안내 한 문장 1회 |
