# 영상과 요약 이미지 설계 (V1.3.0)

- 작성일: 2026-10-28
- 대상 버전: V1.3.0 (versionCode 10300, debug `1.3.0-dev`, 화면 `V1.3.0`)
- 브랜치: `feature/video-v1.3.0` (`feature/trips-v1.2.0`의 V1.2.1 위에서 시작 — V1.2.1은 아직 main에 합치지 않음)
- 선행: `2026-10-18-trips-postprocess-design.md`(V1.2.0·V1.2.1 — 사진 위치·숨김, 심박·심박 색, 주행별 색, 단순화 경로, 오프라인 지도)
- 상태: 1~5부 사용자 승인(2026-10-28 채팅)

## 0. 목적과 범위

bikeRecoder 4단계 로드맵의 4단계다. **완료된 여행**으로 휴대폰 안에서(서버 없음) 다음을 만든다.

1. **Relive식 3D 영상(MP4)**: 기울어진 3D 지도 위로 경로가 그려지며 따라가고, 사진을 찍은 곳에서 사진이 나타나며, 진행은 실제 이동 시간에 비례한다. 여러 날 여행은 모든 날을 이어 영상 하나.
2. **요약 이미지(PNG)**: 경로 지도, 핵심 숫자, 사진 최대 3장을 한 장에.

용도는 SNS 공유와 보관 둘 다 — 비율(세로 9:16 / 가로 16:9)과 길이(짧게/보통/길게)를 고른다.

**범위 밖:** 앱에 넣어 둔 음악(사용자 파일만), 동영상 클립 넣기, 실시간(주행 중) 생성, 서버 업로드, 영상 편집(자르기·자막 수정).

## 1. 진입과 옵션

### 1.1 만드는 곳
- **여행을 완료할 때:** 당일 여행이 끝나거나 여러 날 여행에서 [여행 완료] 뒤의 구간 요약(기록 화면·안내 화면 요약 공통) 아래에 **[영상 만들기] [이미지 만들기]**.
- **여행 기록 화면:** 완료된(COMPLETED) 여행이면 위쪽에 **[영상 만들기] [이미지 만들기]**. 진행 중(ACTIVE) 여행에는 없음.
- 대상은 여행의 끝난 구간 중 거리 10 m 이상(`MIN_RIDE_DISTANCE_M`)인 구간들(시간순). 그런 구간이 없으면 버튼을 숨긴다.

### 1.2 영상 옵션 화면
| 항목 | 선택지 | 기본값 |
|---|---|---|
| 화면 비율 | 세로 9:16 / 가로 16:9 | 세로 |
| 길이 | 짧게(약 30초) / 보통(약 1분) / 길게(약 2분) | 보통 |
| 사진 넣기 | 켬 / 끔 | 켬(숨긴 사진 제외) |
| 숫자 표시(거리·속도·고도·심박) | 켬 / 끔 | 켬 |
| 경로 색 | 기본 / 심박 | 기본([심박]은 심박이 자세한 구간이 있는 여행만) |
| 배경음악 | 없음 / [음악 고르기] | 없음 |

- 아래에 예상 소요 시간 **"약 N분 걸립니다"**(§3.6), 버튼 **[만들기]**.
- 마지막으로 고른 옵션(음악 제외)은 기억한다(DataStore).

### 1.3 이미지
- 고르는 것은 **화면 비율**뿐. [만들기] → 몇 초.

## 2. 영상의 흐름

초당 **24장**. 순서: **시작 3초 → 주행(사진 장면 포함) → 끝 4초**.

### 2.1 시작 (3초)
- 0~1.5초: 전체 경로가 화면에 들어오는 지도(위에서 내려다봄, 기울기 0) + 가운데 큰 글씨: 날짜("10월 25일 (일)", 여러 날이면 "10월 17일 ~ 18일"), "당일" / "여러 날 · N일", 총 거리.
- 1.5~3초: 카메라가 출발점으로 내려가며 기울기 0° → 55°, 확대 → 주행 확대(§2.2)로 부드럽게 바뀐다(글자는 사라진다).

### 2.2 주행
- **카메라:** 기울기 **55°**, 확대(zoom) **15.5**, 방향은 진행 방향(현재 위치에서 경로를 따라 **150 m 앞**을 바라봄), 방향 변화는 부드럽게(초당 최대 60°, 지수 평활). 위치는 경로 위 현재 지점.
- **경로:** 지나온 길은 진한 선(두께 6, 주행별 색 — 여러 날은 날마다 `RideColors` 색; [심박]이면 §V1.2 심박 색), 남은 길은 흐린 선(두께 4, 불투명도 0.35). 현재 위치에 흰 테두리 점.
- **속도 비례(시간 매핑):** 영상의 주행 장면 시간 `[0, R]`을 여행의 **이동 시간**(일시정지 제외, 구간 사이 쉬는 시간 제외)에 선형으로 맞춘다. 즉 같은 영상 시간 동안 빨리 달린 곳은 더 멀리 지나간다. 각 프레임의 위치 = 그 이동 시각의 기록 지점 사이 보간.
- **숫자 표시(켬일 때):** 화면 아래 띠에 지금까지 거리 · 지금 속도(km/h, 앞뒤 10초 평균) · 고도 · 심박(그 시각 ±30초 안 샘플, 없으면 칸 생략).
- **여러 날:** 날이 바뀌는 지점에서 **"N일째 · M월 d일"** 자막을 1.5초(진행은 멈추지 않음).

### 2.3 사진 (사진 넣기 켬)
- 사진을 찍은 위치(그 사진의 촬영 시각에 해당하는 이동 시각)에 오면 지도가 멈추고, 사진이 가운데에 크게(화면 폭의 80%, 둥근 모서리, 흰 테두리) 나타나 **2.5초**(나타남 0.4초 · 보임 1.7초 · 사라짐 0.4초), 사진 아래 찍은 시각 "오후 8:49".
- 길이별 **사진 상한**: 짧게 4장, 보통 8장, 길게 15장. 숨기지 않은 사진이 상한보다 많으면 이동 시간 축에서 고르게 퍼지도록 고른다(구간을 상한 수로 나눠 각 칸에서 칸 가운데에 가장 가까운 사진).
- 같은 이동 시각(±1초)의 사진 여러 장은 이어서 나온다.

### 2.4 끝 (4초)
- 전체 경로 지도(위에서, 지나온 색으로 전부) + 요약 카드: 총 거리 · 이동 시간 · 평균/최고 속도 · 상승 고도 · 평균 심박·칼로리(있을 때만), 맨 아래 작게 "bikeRecoder". 마지막 1초는 서서히 어두워짐.

### 2.5 길이 계산
- 전체 길이 T: 짧게 30초, 보통 60초, 길게 120초.
- 주행 장면 R = T − 3 − 4 − 2.5 × (넣는 사진 수). R이 T의 50%보다 작아지지 않도록 사진 상한이 정해져 있다(§2.3).
- 이동 시간이 R보다 짧은 여행(예: 20초 이동)은 R = 이동 시간(배속 1 미만으로 늘리지 않음) → 전체 길이가 짧아진다.

## 3. 그리기와 영상 만들기

### 3.1 단계
1. **준비:** 경로(대상 구간 지점들) 주변 지도를 내려받는다 — 기존 오프라인 지도 기능(`MapLibreOfflineController`)으로 경로 둘레 확대 13~16, 영상 목적(`kind = VIDEO`) 표시. 인터넷이 없고 받아 둔 지도도 없으면 시작 전 **"지도를 받으려면 인터넷이 필요합니다"**. 영상 목적 지도는 영상이 끝나면(성공·실패·취소) 지운다.
2. **장면 계산(`:core`, 순수 Kotlin):** 프레임마다 `FrameSpec(kind, camera(lat, lon, zoom, bearing, tilt), doneUntil(구간·지점 인덱스와 보간 비율), hud, photo?, caption?, fade)`를 만든다. 시간 배분·속도 비례·사진 고르기·카메라 평활·자막이 여기 있다.
3. **1장씩 그리기(앱):** 화면 밖 `MapSnapshotter`로 그 카메라의 3D 지도 1장 → 그 위에 Canvas로 경로(스냅샷의 위경도→픽셀 변환으로 그려 3D 기울기에 정확히 맞음)·숫자 띠·사진 카드·자막·어두워짐을 덧그린다. 카메라가 같은 프레임(시작 0~1.5초, 사진 장면, 끝)은 지도 스냅샷을 한 번만 찍고 재사용한다.
4. **인코딩:** `MediaCodec`(H.264, 1080×1920 또는 1920×1080, 24fps, 약 8 Mbps, 키프레임 1초) 입력 Surface에 그린 Bitmap을 그리고 `MediaMuxer`로 MP4.
5. **배경음악(골랐을 때):** 고른 파일을 `MediaExtractor`+`MediaCodec`으로 PCM까지 풀어 영상 길이로 자르고(짧으면 반복하지 않고 그 길이까지), 마지막 2초를 서서히 줄여 AAC(128 kbps, 44.1 kHz 스테레오)로 다시 인코딩해 같은 MP4에 넣는다.

### 3.2 실행
- **포그라운드 서비스**(Android 15 이상 `mediaProcessing` 종류, 그 아래는 `dataSync`)로 돈다 — 화면을 나가거나 꺼도 계속.
- 알림: **"영상 만드는 중 42% · 약 2분 남음"** + [취소]. 끝나면 **"영상을 만들었습니다"**(누르면 미리보기).
- 한 번에 하나만. 만드는 중에 또 누르면 **"이미 영상을 만들고 있습니다"**.
- **주행 기록 중에는 만들지 않는다**: **"기록 중에는 만들 수 없습니다"**. 만드는 중에 기록이 시작되면 영상 작업을 멈추고 지운다(GPS 기록 우선) — 알림 "기록이 시작되어 영상 만들기를 멈췄습니다".
- 배터리 20% 미만이고 충전 중이 아니면 시작 전 한 번 확인 **"배터리가 부족합니다(N%). 계속할까요?"** [계속] [취소].
- 요약 이미지도 같은 서비스·준비 단계를 쓰되 몇 초 안에 끝난다.

### 3.3 취소·실패
- [취소]나 실패 → 만들던 파일(갤러리 임시 항목)을 지운다.
- 앱이 강제 종료되어 끝나지 못한 작업은 다음 실행 때 **"영상을 만들지 못했습니다. 다시 만들까요?"** [다시 만들기] [닫기](같은 옵션).

### 3.4 오류
- 저장 공간 부족(시작 전 예상 크기 = 8 Mbps × 길이 × 1.2 확인, 중간 실패 포함): **"저장 공간이 부족합니다(약 N MB 필요)"**.
- 음악 파일을 읽을 수 없음: **"음악 파일을 읽을 수 없습니다. 음악 없이 만들까요?"** [음악 없이 만들기] [취소].
- 인코더가 1080 크기를 지원하지 않음(구성 실패): 720×1280(또는 1280×720)으로 다시 시도하고 끝난 뒤 **"이 휴대폰은 720p로 만들었습니다"**.
- 지도 일부가 끝내 안 받아짐: 받아진 부분만 그리고 계속(빈 타일은 배경색).

### 3.5 저장과 공유
- 영상: 갤러리 **Movies/bikeRecoder**, 이미지: **Pictures/bikeRecoder**, 이름 `bikeRecoder_yyyyMMdd_HHmm.mp4/.png`(여행 첫 구간 시작 시각; 같은 이름이 있으면 `_2`…). MediaStore에 `IS_PENDING`으로 쓰고 끝나면 공개.
- 다 만들면 **미리보기 화면**(영상은 재생, 이미지는 보기) + **[공유]**(공유 시트) **[갤러리에서 보기]**.
- 권한: 앱이 만든 파일의 갤러리 저장은 권한 불필요. 음악은 파일 선택 창(`ACTION_OPEN_DOCUMENT`, `audio/*`)으로 고른 파일만 읽음.

### 3.6 예상 시간
- 예상 = 프레임 수 × 장당 시간. 장당 시간은 기본 0.25초, 이 휴대폰에서 마지막으로 만든 영상의 실제 값이 있으면 그것(DataStore). 지도를 다시 찍지 않는 프레임은 0.03초로 센다. 분 단위 올림, 최소 1분.

## 4. 요약 이미지

- 크기: 세로 1080×1920 / 가로 1920×1080.
- **세로:** ① 머리: 날짜 + "당일" / "여러 날 · N일" ② 지도(약 절반, 위에서 내려다봄, 전체 경로가 맞게, 주행별 색, 출발·도착 점, 사진 위치 작은 동그라미) ③ 숫자 2줄×3칸: 거리 · 이동 시간 · 평균 속도 / 최고 속도 · 상승 고도 · 평균 심박(없으면 "주행 N회") ④ 사진 줄(있을 때만, 최대 3장, 숨긴 것 제외, 이동 시간에 고르게) ⑤ 바닥 작게 "bikeRecoder".
- **가로:** 왼쪽 60% 지도, 오른쪽 40%에 머리·숫자·사진 줄.
- 지도 1장(`MapSnapshotter`) + Canvas → PNG.

## 5. 저장소·권한·검증

### 5.1 만든 파일 기록 (DB 4 → 5)
- 새 표 `trip_media(id, tripId(FK, 여행 삭제 시 함께 삭제), kind(VIDEO/IMAGE), uri, createdAt, optionsJson)` — `AutoMigration(4, 5)`, 표 추가만.
- 여행 기록 화면: **"만든 영상·이미지"** 줄(가로 미리보기 목록, 영상은 ▶ 표시) — 누르면 갤러리 앱(보기 인텐트)으로. 화면을 열 때 갤러리에서 지워진 항목은 기록에서 뺀다.
- 여행을 지워도 갤러리의 파일은 지우지 않는다(이미 내보낸 파일).
- 끝나지 못한 작업(§3.3)은 `trip_media`가 아니라 DataStore의 "진행 중 작업"(tripId, 옵션, 시작 시각)으로 기억한다.

### 5.2 권한
- 새 권한 없음. 매니페스트: 포그라운드 서비스 종류 `mediaProcessing`(+ `FOREGROUND_SERVICE_MEDIA_PROCESSING`), 낮은 버전용 `dataSync`(+ `FOREGROUND_SERVICE_DATA_SYNC`). 알림 권한은 기존 것.

### 5.3 검증
- **PC 테스트(JUnit5, `:core`):** 시간 배분(길이별 프레임 수, R 계산, 짧은 이동 시간), 속도 비례(이동 시간 선형, 일시정지·구간 사이 제외), 사진 상한·고르기·같은 시각 연속, 카메라 평활(방향 변화 상한, 150 m 앞), 여러 날 자막 위치, 시작·끝 카메라, 예상 시간, 음악 자르기·페이드 계산, 이미지 배치 계산(세로·가로, 사진 0~3장, 심박 없음), 파일 이름.
